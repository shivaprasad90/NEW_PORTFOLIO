## 🚀 Installation & Setup

### Prerequisites
Make sure you have Node.js (v18+) installed on your machine.

### 1. Clone or Open Project
Navigate to the root directory of the project:
```bash
cd "my portfolio"
```

### 2. Install Dependencies
Run the following command to install required npm packages:
```bash
npm install
```

### 3. Run Development Server
Start the Vite local development server:
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000`.

### 4. Build for Production
To build the application for deployment:
```bash
npm run build
```

## 🖼️ How to Replace the Profile Photo

1. Prepare your photo in JPG format (preferably high resolution & square aspect ratio).
2. Rename your photo file to `profile.jpg`.
3. Replace the existing `profile.jpg` in the `public/` directory:
   ```
   public/profile.jpg
   ```
4. The website will automatically update the circular hero portrait.

---

## 📄 How to Replace the Resume

1. Prepare your latest PDF resume.
2. Rename your PDF file to `resume.pdf`.
3. Replace the existing `resume.pdf` in the `public/` directory:
   ```
   public/resume.pdf
   ```
4. The "Download Resume" button will automatically download your updated PDF file.

## 🌐 How to Deploy the Project

### Deploying to Vercel
1. Push your project repository to GitHub.
2. Sign in to [Vercel](https://vercel.com).
3. Import your GitHub repository.
4. Set Framework Preset to **Vite**.
5. Click **Deploy**.

### Deploying to Netlify
1. Log in to [Netlify](https://netlify.com).
2. Drag and drop the compiled `dist/` directory generated after running `npm run build`, or connect your GitHub repository with build command `npm run build` and publish directory `dist`.
